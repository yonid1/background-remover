# מסיר רקע

כלי שמסיר את הרקע מתמונות ומחליף אותו בצבע, מעבר צבעים, טשטוש או תמונה אחרת.
הכול רץ בדפדפן: התמונות לא נשלחות לשום שרת.

**לשימוש באתר:** https://yonid1.github.io/background-remover/

## מה אפשר לעשות

- **הסרת רקע אוטומטית**, עם בחירה בין כמה מודלים של בינה מלאכותית (פירוט בהמשך).
- **כמה תמונות בבת אחת:** התמונות מעובדות אחת אחרי השנייה. לכל תמונה יש חיתוך ותיקונים משלה,
  ואפשר להוריד את כולן יחד כקובץ ZIP.
- **רקע חדש:** שקוף, צבע, מעבר צבעים (9 כיוונים), טשטוש של הרקע המקורי, או תמונה אחרת.
- **אפקטים:** צל רך מתחת לאובייקט, וקו מתאר בצבע לבחירה (מראה של סטיקר).
- **חיתוך:** מסגרת שגוררים, יחסים קבועים (1:1, 4:5, 9:16 ועוד) והתאמה אוטומטית לאובייקט.
- **מרכוז עם שוליים:** התמונה נבנית סביב האובייקט, גם מעבר לקצוות של התמונה המקורית. מתאים לתמונות מוצר.
- **תיקון ידני במברשת:** מחיקה של שאריות רקע, ושחזור של חלקים שהמודל הוריד בטעות.
- **ביטול וחזרה** (‎⌘Z / ⌘⇧Z, או Ctrl+Z / Ctrl+Y) על שינויי הגדרות, חיתוכים ומשיכות מברשת.
- **שמירה:** PNG, ‏JPG או WEBP, בגודל מקורי או מוקטן (2048 / 1080), העתקה ללוח, ובטלפון גם שיתוף ושמירה לתמונות.
- **מצב כהה**, לפי הגדרות המערכת או בבחירה ידנית.
- **אפליקציה להתקנה (PWA):** אפשר להוסיף למסך הבית, ואחרי השימוש הראשון הכלי עובד גם בלי אינטרנט.
- הדפדפן זוכר את ההגדרות האחרונות. תמונות גדולות מאוד (כמו 24 מגה-פיקסל מאייפון) מוקטנות ל-16 מגה-פיקסל.

## המודלים

| מודל | הורדה | מתאים ל | רישיון |
|---|---|---|---|
| **ISNet** (ברירת מחדל) | 88MB | רוב התמונות, מהיר | AGPL-3.0 (דרך ‎@imgly/background-removal) |
| **RMBG** (גרסה 1.4) של BRIA | 88MB | קצוות נקיים יותר ברוב התמונות | שימוש לא מסחרי בלבד ([bria-rmbg-1.4](https://huggingface.co/briaai/RMBG-1.4)) |
| **MODNet** | 26MB | פורטרטים של אנשים, שיער | Apache-2.0 |
| **BiRefNet Lite** (ניסיוני) | 115MB | קצוות מדויקים מאוד | MIT |

כל מודל מורד רק בפעם הראשונה שמשתמשים בו. המודלים חוץ מ-ISNet צריכים דפדפן עם WebGPU (כמו כרום עדכני).

**BiRefNet לא רץ על מק ואייפון**, ולכן הוא כבוי שם. בבדיקה (כרום 156 על מק עם שבב M), הקוד של BiRefNet
לכרטיס המסך צריך 11 "storage buffers" לכל פעולה, וכרטיסי מסך של Apple מאפשרים רק 10. זה קרה גם עם Transformers.js 4.3
וגם עם 3.8. על המעבד (בלי כרטיס מסך) נגמר לו הזיכרון. במחשבים אחרים זה תלוי בכרטיס המסך, ולא נבדק.

## הרצה במחשב

צריך [Node.js](https://nodejs.org) (גרסה 20 ומעלה).

```bash
npm install      # פעם ראשונה בלבד: מתקין את הספריות
npm run dev      # מריץ שרת פיתוח: http://localhost:5173
```

פקודות נוספות:

```bash
npm run build    # בונה גרסה סופית לתיקייה dist/
npm run preview  # מציג את הגרסה הסופית במחשב
npm run typecheck
```

## פרסום

כל שינוי שנכנס לענף `main` נבנה ומתפרסם אוטומטית ב-GitHub Pages
(ראו `.github/workflows/deploy.yml`). ב-Pull Request הבנייה רק נבדקת, בלי לפרסם.

## טכנולוגיות

[‎@imgly/background-removal](https://github.com/imgly/background-removal-js),
[Transformers.js](https://github.com/huggingface/transformers.js) (גרסה 3.8) ו-[fflate](https://github.com/101arrowz/fflate).

- **RMBG 1.4 של BRIA:** מותר לשימוש לא מסחרי בלבד.

לשימוש אישי הכול בסדר. לפני שמפיצים או מוכרים את הכלי כדאי לבדוק מה הרישיונות דורשים.
