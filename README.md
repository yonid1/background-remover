# מסיר רקע

כלי שמסיר את הרקע מתמונה ומחליף אותו בצבע, מעבר צבעים, טשטוש או תמונה אחרת.
הכול רץ בדפדפן: התמונות לא נשלחות לשום שרת.

## מה אפשר לעשות

- **הסרת רקע אוטומטית** בעזרת מודל בינה מלאכותית (ISNet), שרץ על כרטיס המסך דרך WebGPU.
- **רקע חדש:** שקוף, צבע, מעבר צבעים (9 כיוונים, כולל מצד לצד ועגול), טשטוש של הרקע המקורי, או תמונה אחרת.
- **חיתוך:** מסגרת שגוררים, יחסים קבועים (1:1, 4:5, 9:16 ועוד), והתאמה אוטומטית סביב האובייקט.
- **השוואה למקור** בלחיצה ממושכת, ו**הורדה** כ-PNG או JPG.
- בחירת תמונה מהמחשב, גרירה לדף או הדבקה (‎⌘V / Ctrl+V).

## הרצה במחשב

צריך [Node.js](https://nodejs.org) (גרסה 20 ומעלה).

```bash
npm install      # פעם ראשונה בלבד: מתקין את הספריות
npm run dev      # מריץ שרת פיתוח: http://localhost:5173
```

פקודות נוספות:

```bash
npm run build    # בונה גרסה סופית לתיקייה dist/
npm run preview  # מציג את הגרסה הסופית במחשב
npm run typecheck
```

בשימוש הראשון הדף מוריד את המודל (בערך 90MB) ולכן צריך אינטרנט. אחר כך הדפדפן שומר אותו.

```
src/
├── main.tsx                  נקודת הכניסה

├── constants.ts              צבעים, כיווני מעבר, יחסי חיתוך, המודל
├── lib/                      לוגיקה בלי React
│   ├── removal.ts            טעינת הספרייה והמודל והסרת הרקע

│   └── image.ts              פתיחת קבצים והורדה

│   ├── useBackgroundRemoval.ts   מריץ הסרה לכל תמונה חדשה
│   ├── useFileDropAndPaste.ts    גרירה והדבקה של תמונות
│   └── useToast.ts               הודעות קצרות
└── components/
    ├── Stage.tsx             אזור התצוגה
    ├── CropOverlay.tsx       מסגרת החיתוך שגוררים
    ├── StatusOverlay.tsx     התקדמות והודעות שגיאה
```
